Key Points
  • Sequential Rule Processing (Top to Bottom).
  • First Match Principle decides the action.
  • Implicit deny for unmatched packets.
  • Directional application: inbound or outbound.
ACL Types

1) Standard ACL: filter by source IP only.

2) Extended ACL: filter by source/destination IP, protocol, and ports.

Best practice: place extended ACLs close to the source.

When is ACL Used?
  • Network security and host protection.
  • Filtering specific traffic (Telnet/FTP/HTTP).
  • Classifying traffic for NAT/VPN.
  • QoS traffic prioritization.
Quick Facts

• ACLs operate mainly at Layer 3 and Layer 4.

• Wildcard masks define ranges and matching logic.

• ACL direction matters per interface (in/out).

• Every ACL ends with an implicit deny.

Key Terms
  • Permit: allows traffic.
  • Deny: blocks traffic.
Extra Notes

• Order is critical: top rules are checked first.

• Keep ACLs readable and minimize overlap.

• Test ACL changes before production deployment.
